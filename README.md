# PremJapa - Radha Name Counter (Android)

A modern Android app for daily **Radha Naam Japa** tracking with a serene devotional UI.

## Features
- One-tap chanting counter (`Chant +1`) with decrement support.
- Daily progress toward your sankalpa goal.
- Adjustable daily goal (9 to 1008 names).
- Lifetime total count.
- Current and best streak tracking.
- Local persistence via SharedPreferences.
- Reset options for today-only or full history.

## Tech
- Kotlin
- Jetpack Compose + Material 3
- ViewModel + StateFlow

## Run
1. Open in Android Studio (Hedgehog+ recommended).
2. Sync Gradle.
3. Run app on Android 8.0+ device/emulator.
